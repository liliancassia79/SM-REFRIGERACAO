# ❄️ SM Refrigeração - Landing Page Premium

![Status do Projeto](https://img.shields.io/badge/Status-Concluído-brightgreen)
![Tecnologias](https://img.shields.io/badge/Stack-HTML%20%7C%20CSS%20%7C%20JS-blue)

Uma Landing Page de alta conversão desenvolvida para o setor de **Climatização e Refrigeração**. O projeto foca em uma experiência visual "Premium" (Dark Mode com Neon), transmitindo modernidade e confiança técnica.

## 🚀 Funcionalidades Principais

* **🎨 Design Neon & Dark:** Estética moderna que destaca a tecnologia dos serviços.
* **📱 Totalmente Responsivo:** Menu Mobile e grid adaptável para celulares e tablets.
* **💬 Sistema de Avaliações (DOM):** Clientes podem postar depoimentos que aparecem instantaneamente na tela via JavaScript.
* **🔄 Antes e Depois:** Componente visual para comparação de serviços de limpeza/manutenção.
* **📞 Botões de Conversão:** WhatsApp flutuante e Modais (Pop-ups) para Orçamento e Contato sem recarregar a página.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica e acessível.
* **CSS3:** Flexbox, Grid Layout, Animações (Keyframes), Variáveis CSS e Backdrop-filters.
* **JavaScript (Vanilla):** Manipulação do DOM para interatividade dos modais e comentários.
* **Font Awesome & Google Fonts:** Tipografia e ícones vetoriais.

## ▶️ Como visualizar localmente

1. Abra um terminal na pasta `site1`.
2. Inicie um servidor local simples (Python 3):

```bash
python3 -m http.server 8000
```

3. Abra o navegador em `http://localhost:8000` para testar.
